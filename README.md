## Qué incluye

- **40 diapositivas del PowerPoint** integradas dentro de sus secciones correspondientes
- Cada sección muestra la(s) diapositiva(s) base en formato hero, side-by-side o secuencia
- Evidence Board con las 40 diapositivas como síntesis visual
- Menú sticky + índice lateral (desktop) + hamburguesa (móvil)
- Scroll reveal, animaciones, microinteracciones
- Paleta interactiva con click-to-copy HEX

## Publicar en GitHub Pages

1. Sube todos los archivos a un repositorio público
2. **Settings → Pages → Source: Deploy from branch → main → / (root)**
3. Listo en: `https://tu-usuario.github.io/nombre-repo`

> El archivo `.nojekyll` ya incluido evita que GitHub Pages ignore archivos con guion bajo.
